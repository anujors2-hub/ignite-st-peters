# Ignite Medical Resort — St. Peters

Luxury marketing page for Ignite Medical Resort's St. Peters, MO location.

Built with **React 19**, **Vite 8**, and **Tailwind CSS 4**.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment

Deployed on [Vercel](https://vercel.com). Push to `main` triggers automatic deployment.
